Scoring pool Every score on this page is computed against the entire 1,000-company candidate pool — the same percentile-ranking basis the methodology uses — regardless of the display filters above (search, country, top-N) which only control what's shown, not what's ranked against what. What's fixed vs. live Revenue consistency, track record, dilution, profitability, cash-flow, revenue growth and dividend consistency are computed directly from the Capital IQ financial history and don't change here. Gross margin (18 pts, banded) and valuation (18 pts, best-of-three lenses: GM-adjusted P/S, ROE-adjusted P/B, growth-adjusted earnings yield) recompute live from whatever market cap and gross margin you enter. Companies without a verified gross margin use the pool's median GM-band score as a neutral fallback, and are flagged needs GM so you can prioritise them. Companies already refreshed through the data pipeline (below) are flagged mc refreshed. This page is static — how updates actually happen This is a plain, self-contained HTML file with no server and no database: it was generated from the data in this repository's data/ folder at build time. Typing a new market cap or gross margin into the table only changes what you see, in this browser — it's saved to this device's local storage (not shared, not synced anywhere) so it survives a reload, but nobody else who opens this page will see it, and it disappears if you clear site data. Use it freely to try scenarios.

To make an update permanent — visible to everyone who loads the page — edit data/mc_overrides_applied.json (or data/gm_overrides_applied.json) in the repo with the new value and its source, run python3 scripts/build_site.py, and push. The Update market caps / Update gross margins buttons below build you a ready-to-paste list of the current values in the right format as a starting point for that file. Historical record Every time you apply an update from these buttons, a full snapshot of the pool as it stood right before is downloaded as a dated .xlsx file — save it into this repo's snapshots/ folder (or run python3 scripts/snapshot.py directly) to keep a permanent record alongside the data change. Formula note Dilution banding, the growth power-curve, and percentile tie-handling are this dashboard's best-effort reimplementation of the methodology document — expect the odd rank to differ by a place or two from a prior manual run.
